TensorForge: Multi-Precision Tensor Core Design Space Explorer

Explore tensor-core configurations using synthesized area and power data, with traceable estimates when available.

Synthesis conditions: Design Compiler · TSMC 22nm

Configuration

Number of output rows. Array estimates use M × N identical dot-product units.
Number of output columns. Together with M, this determines the unit count used in array estimates.
Number of terms in each dot product. The theoretical operation count is 2 × M × N × K per cycle, counting multiplication and addition separately.
The target clock used during hardware synthesis, in MHz. Only released clock configurations are available.
A combined name selects a unit supporting the listed formats, not just one workload mode. FP4LUT denotes the lookup-table FP4 implementation. Raw configuration identifiers are preserved.
Match the MX microscaling flag in the released configuration (withMX / noMX). MX and NV are separate flags; not all combinations have data.
Match the separate NV format/scale variant flag in the released configuration (withNV / noNV). Available results depend on the other selected settings.
Normalization/alignment format in the floating-point path. Codes 4 and 8 in the reports identify integer INT4 and INT8 paths; they are displayed as integer-path options.
Format of the accumulator used to sum products, such as FP32 or INT32. It can differ from the input precision.
Output-format configuration from the synthesis reports. Combined format names preserve the original configuration, independently of the input and accumulator formats.
The original midMat parameter distinguishes intermediate arithmetic/datapath configurations. Its available values come from the released designs; it is separate from M, N, and K.
Try the released offline prediction table only after both array and unit synthesis lookups fail. This does not run a model for arbitrary new configurations.

Results

Synthesized array: use the full array report. Derived unit: multiply measured unit costs by M × N. Predicted unit: scale an offline model estimate. The latter two are array estimates.
